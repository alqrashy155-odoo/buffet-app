# ☕ تطبيق البوفية — إدارة الإيرادات والمصروفات وحركة النقدية

تطبيق ويب بسيط بواجهة مستوحاة من أودو. يعمل على الجوال والكمبيوتر، وبياناته مشتركة بين المستخدمين لحظياً عبر Supabase، ومستضاف مجاناً على GitHub Pages.

## الشاشات
| الشاشة | الوظيفة |
|---|---|
| لوحة المتابعة | رصيد الصندوق، مبيعات ومصروف اليوم، ملخص الشهر، رسم الحركة النقدية اليومية، والمصروفات حسب البند |
| الحركات | قائمة أو بطاقات، مع بحث وفلاتر (النوع، البند، المستخدم، الفترة) وتصدير Excel |
| حركة جديدة | بيع / صرف / سحب من النقدية / تسوية + / تسوية − / رصيد افتتاحي |
| الإقفال اليومي | جرد النقدية بالفئات ومقارنته بالرصيد الدفتري، ويُسجَّل الفرق تسويةً تلقائياً |
| التقارير | كشف حركة الصندوق، ملخص الإيرادات والمصروفات، تقرير حسب البند (شهري)، الملخص اليومي، مع تصدير Excel وطباعة PDF |
| البنود | إضافة البنود وتعديل أسمائها وترتيبها وإيقافها |
| المستخدمون والصلاحيات | الدور (مدير/مستخدم) وصلاحيات: إضافة، تعديل، حذف، إدارة البنود |

**معادلة الرصيد:** رصيد أول المدة + المبيعات + الأرصدة الافتتاحية − المصروفات − المسحوبات ± التسويات = رصيد آخر المدة

## خطوات التشغيل (مرة واحدة فقط، حوالي 15 دقيقة)

### 1) إنشاء قاعدة البيانات في Supabase
1. افتح [supabase.com/dashboard](https://supabase.com/dashboard) ثم **New project**. سمّه `buffet`، واختر كلمة مرور لقاعدة البيانات، ومنطقة قريبة (مثل Frankfurt أو Mumbai).
2. بعد إنشاء المشروع: من القائمة الجانبية افتح **SQL Editor** ثم **New query**.
3. انسخ محتوى ملف `schema.sql` كاملاً والصقه، ثم اضغط **Run**. يجب أن تظهر رسالة `Success`.

### 2) إيقاف التسجيل العام (مهم للأمان)
**Authentication → Sign In / Providers** ثم أوقف **Allow new users to sign up**.
بهذا لا يستطيع أحد إنشاء حساب بنفسه، فأنت من يضيف المستخدمين.

### 3) إضافة المستخدمين
**Authentication → Users → Add user → Create new user**
- أضف **نفسك أولاً**: إيميلك وكلمة مرور، وفعّل **Auto Confirm User**. أول مستخدم يُضاف يصبح **مديراً** تلقائياً.
- ثم أضف أخاك بنفس الطريقة. يبدأ حسابه بصلاحية «اطلاع فقط».

### 4) ربط التطبيق بقاعدة البيانات
**Project Settings → API** وانسخ قيمتين:
- **Project URL**
- **anon public key**

افتح الملف `config.js` وضع القيمتين:
```js
SUPABASE_URL: 'https://xxxx.supabase.co',
SUPABASE_ANON_KEY: 'eyJhbGciOi...',
```
> مفتاح anon آمن للنشر، لأن الحماية مطبّقة داخل قاعدة البيانات (RLS). **لا تضع أبداً** مفتاح `service_role`.

### 5) النشر على GitHub Pages
1. في GitHub: **New repository** باسم `buffet-app` (Public)، ثم **Create**.
2. اضغط **uploading an existing file** واسحب **محتويات** المجلد كلها (`index.html` ومجلدات `css` و`js` و`supabase` وملف `README.md`)، ثم **Commit changes**.
3. افتح **Settings → Pages**، واختر في **Source**: `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين يظهر الرابط: `https://اسم-حسابك.github.io/buffet-app/`

### 6) أول استخدام
1. سجّل الدخول بحسابك، ثم سجّل **رصيداً افتتاحياً** بالمبلغ الموجود في الصندوق الآن.
2. افتح **الإعدادات ← المستخدمون والصلاحيات**، وفعّل لأخيك (إضافة / تعديل / حذف)، ثم اضغط **حفظ**.
3. أرسل له الرابط مع إيميله وكلمة المرور. يستطيع تغيير كلمة المرور من «حسابي».

> 💡 على الجوال: افتح الرابط ثم اختر **إضافة إلى الشاشة الرئيسية**، فيعمل كتطبيق.

## تعديلات لاحقة
- **اسم البوفية والعملة:** من `config.js` (`APP_NAME` و`CURRENCY`).
- **أي تعديل على الملفات:** ارفع الملف المعدّل في GitHub بنفس المسار، ويتحدّث الموقع خلال دقيقة.
- **قبل الربط بـ Supabase** يعمل التطبيق في وضع تجريبي محلي ببيانات عيّنة.

## الملفات
```
index.html           الصفحة الرئيسية
css/style.css        التنسيق (أسلوب أودو)
js/config.js         الإعدادات ← تعدّله أنت
js/app.js            منطق التطبيق
supabase/schema.sql  قاعدة البيانات والصلاحيات
```
